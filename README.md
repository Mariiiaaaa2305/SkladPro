# СкладPro — система управління складом

Вебзастосунок для управління складськими запасами, товарами, постачальниками та складськими операціями.

**Технології:** Python, Flask, MySQL, Jinja2, HTML/CSS, pytest.

## Запуск

### 1. Клонування репозиторію

```bash
git clone <URL_репозиторію>
cd warehouse_management
```

### 2. Встановлення залежностей

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. Налаштування середовища

Створи файл `.env` на основі `.env.example` і налаштуй параметри підключення до MySQL.

```env
SECRET_KEY=replace-with-a-random-secret
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=
MYSQL_DATABASE=warehouse_management
```

### 4. Підготовка бази даних

```bash
mysql -u root -p < database/schema.sql
mysql -u root -p warehouse_management < database/seed.sql
```

Якщо база даних уже створена та містить початкові дані, повторно запускати SQL-скрипти не потрібно.

### 5. Запуск застосунку

```bash
python run.py
```

Відкрийте [http://127.0.0.1:5000](http://127.0.0.1:5000).

## Функціональні можливості

- Авторизація користувачів і розмежування доступу за ролями.
- Облік товарів і складських запасів.
- Управління постачальниками та контрагентами.
- Облік складських рухів і документів.
- REST API для роботи з товарами.
- Адміністративна панель для управління користувачами.
- Керування ролями та активністю облікових записів.

Паролі зберігаються в базі даних у вигляді хешів, тому їх не можна прочитати безпосередньо з БД.

### Ролі та права доступу

- **Адміністратор** — доступ до адміністративної панелі, керування користувачами, ролями та активністю облікових записів.
- **Менеджер** — робота з основними функціями складської системи без доступу до адміністративної панелі.
- **Неактивний користувач** — не може авторизуватися до повторної активації облікового запису.

Самостійна реєстрація вимкнена. Нові облікові записи створює адміністратор.

## REST API

API підтримує такі операції з товарами:

| Метод | Опис |
|---|---|
| `GET` | Отримання списку товарів або окремого товару |
| `POST` | Створення товару |
| `PATCH` | Оновлення інформації про товар |
| `DELETE` | Видалення товару |

Для неавторизованих запитів повертається `401 Unauthorized`. Доступ до операцій перевіряється сервером відповідно до прав користувача.

Інтерактивна документація Swagger не налаштована.

## Архітектура та шаблони проєктування

У проєкті використано Flask Blueprints для організації маршрутів, репозиторії для роботи з базою даних і сервіси для реалізації бізнес-логіки.

Реалізовані шаблони GoF:

- **Strategy**
- **Command**
- **Facade**
- **Factory Method**
- **Simple Factory**
- **Observer**
